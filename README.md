# z-slidev

私有 Slidev 维护仓：官方 fork + 本机快捷启动。

- [`slidev/`](https://github.com/0punchman/slidev)：fork 自 [slidevjs/slidev](https://github.com/slidevjs/slidev)，在官方基础上做私有化改造（如 `/remote` 遥控页）。
- `macos-quick-action/`：macOS Finder 右键「演示模式」。
- `windows-quick-action/`：Windows 资源管理器右键「演示模式」。

改内核看 `slidev/`；日常开讲用两边的快捷启动。
